# Derslik. UI başlangıç projesi

Bu repo, Derslik. için modern, duyarlı ve tam çalışan bir React + Vite arayüz prototipini içerir.

## Çalıştırma

1. `npm install`
2. `npm run dev`
3. Tarayıcıda `http://localhost:5173` adresini aç

## Özellikler

- Responsive sidebar ve mobil menü
- Premium hero alanı
- Çalışma istatistik kartları
- Görev takibi
- Ders listesi ve ilerleme çubukları
- Program görünümü
- Not ekleme alanı
- Koyu tema desteği
- Türkçe arayüz

## Not

Bu uygulama, statik kullanıcı deneyimi ve arayüz prototipi olarak tasarlanmıştır; gerçek veritabanı veya kullanıcı kimlik doğrulaması içermez.
